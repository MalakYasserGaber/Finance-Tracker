# 💰 Finance Tracker

A simple personal finance tracker built using **HTML, CSS, and JavaScript**.  
This project helps users track income, expenses, and overall balance while also allowing them to set a budget.

> ⚠️ This project is still in development. More features and UI improvements will be added.

---

## 🚀 Features (Current Version)

- Add income and expense transactions
- Categorize expenses (Food, Bills, Transport, Shopping)
- Automatic calculation of:
  - Total Balance
  - Total Income
  - Total Expenses
- Set and edit monthly budget
- Delete transactions
- Dynamic transaction list rendering
- Basic modal system for adding data

---

## 🧠 How It Works

* The app runs completely in the browser using JavaScript.
* When a transaction is added, it is saved in an array. Each transaction includes the amount, type (income or expense), category, and date.
* The app then recalculates the total balance, income, and expenses every time something changes.
* The UI is dynamically updated using DOM manipulation, meaning changes appear instantly without needing to refresh the page.
* Budget is stored as a simple value that you can set or update anytime.
* No database is used — everything works in real time on the frontend.
